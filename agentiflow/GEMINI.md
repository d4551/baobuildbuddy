# BaoBuildBuddy For Gemini

- Read [`../AGENTS.md`](../AGENTS.md) first, then the three `PROTOCOL` files in this directory.
- Repository reality:
  - Bun 1.3.x
  - TypeScript strict
  - Nuxt 4 SSR
  - Tailwind CSS 4 + daisyUI 5
  - Elysia
  - Drizzle ORM + SQLite
  - Playwright RPA
  - Tauri 2
- Mandatory tools:
  - Context7 for framework and runtime lookups
  - daisyui-blueprint for daisyUI component structure
- Verification baseline:
  - `bun run capability:matrix`
  - `bun run format`
  - `bun run lint`
  - `bun run typecheck`
  - `bun run test`
  - `bun run build`
- Extra verification for automation and desktop work:
  - `bun run verify:desktop-runtime`
  - `bun run verify:desktop-releases`
  - `bun run release:verify`
- Treat `agentiflow/capability-matrix.generated.json` as generated state. Refresh it; do not hand-edit it.
