Local AI Setup

BaoBuildBuddy runs completely local by default using Ollama. No API keys required, no data leaves your machine. Fast, secure inference.

Get Ollama
1

Install Runtime

Download and install the Ollama background daemon for your OS.

2

Pull a Fast Model

Open terminal and download the recommended sub-billion parameter model.

ollama run qwen2.5:0.5b
3

Auto-Detect

Launch BaoBuildBuddy. It automatically connects to the default endpoint.

● http://localhost:11434/v1
