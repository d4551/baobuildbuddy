Set Up Ollama

Set up private AI help on your own computer

BaoBuildBuddy works with Ollama so the app can help with resumes, cover letters, and interview practice right on your computer. Your work stays with you.

Download Ollama
1

Install Ollama

Download Ollama for your computer and finish the basic install.

2

Download a starter model

Paste this one line into Terminal to download the AI model the app can use.

ollama pull llama3.2
3

Open BaoBuildBuddy

Open the app and it will try to find Ollama for you so you can start using AI right away.

● It looks for Ollama automatically.
